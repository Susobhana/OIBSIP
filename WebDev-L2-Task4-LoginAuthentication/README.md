# Forma — Login Authentication System

**Oasis Infobyte Internship — Level 2, Task 4**

## About
A responsive login and registration website featuring a modern interface, form validation, and a personalized dashboard.

## Features
- User registration interface
- Login form
- Email validation
- Password confirmation
- Show and hide password
- Password strength indicator
- Personalized dashboard
- Logout functionality
- Responsive design
- Animated visual elements

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
Open `index.html` in a modern web browser.

An internet connection is recommended for loading the external fonts.

## Security Note
This project is a front-end demonstration. Demo accounts are stored in browser local storage, and passwords are not securely hashed. Do not use real credentials or sensitive information.

A production authentication system requires a secure backend and appropriate password and session management.
