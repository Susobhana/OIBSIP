# Sources and implementation notes

- Built with semantic HTML, CSS, inline SVG artwork, and vanilla JavaScript.
- Typography uses Space Grotesk, DM Sans, Manrope, DM Mono, and Playfair Display from Google Fonts, with browser fallbacks.
- Visual direction: deep plum/violet surfaces, champagne highlights, custom geometric Forma emblem, and static vector hero art. Animation, transitions, ambient blobs, and custom cursor effects are disabled.
- No backend, external authentication provider, or email service is connected. All authentication behavior is simulated locally for demonstration purposes.
